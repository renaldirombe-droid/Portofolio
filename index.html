Klasifikasi Motif Ukiran Tradisional Toraja (MobileNetV2) — Tugas Akhir

Tujuan Proyek: Mengembangkan aplikasi Android untuk melakukan klasifikasi motif ukiran tradisional Toraja secara on-device (di perangkat) guna mendukung identifikasi dan pelestarian warisan budaya Toraja.

Teknologi yang Digunakan: Android (Kotlin), TensorFlow Lite, Arsitektur MobileNetV2, Python (pengolahan dataset & pelatihan model).

Kontribusi Saya: Mengumpulkan dataset gambar motif ukiran Toraja secara langsung di lapangan, melakukan pengolahan & persiapan dataset, serta melatih model MobileNetV2 secara mandiri (model MobileNetV2 dilatih sendiri) hingga diperoleh hasil klasifikasi yang optimal. Mengonversi model ke TensorFlow Lite (TFLite), mengimplementasikan inferensi on-device, serta merancang dan mengembangkan aplikasi Android (Kotlin) sebagai wadah implementasinya, termasuk pengujian dan dokumentasi teknis untuk kebutuhan Tugas Akhir.

Hasil: Aplikasi Android berbasis TFLite yang dapat melakukan klasifikasi motif ukiran Toraja secara on-device (tanpa ketergantungan koneksi internet untuk inferensi utama), dengan model terlatih dan terintegrasi langsung dalam aplikasi.
