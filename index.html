Proyek

Proyek

Klasifikasi Motif Ukiran Toraja — MobileNetV2 (Tugas Akhir)

Aplikasi Android untuk klasifikasi motif ukiran tradisional Toraja secara on-device, guna mendukung identifikasi dan pelestarian warisan budaya Toraja.

Teknologi
Android (Kotlin), TensorFlow Lite, MobileNetV2, Python
Kontribusi
Mengumpulkan dataset gambar motif ukiran langsung di lapangan, melatih model MobileNetV2 secara mandiri, mengonversi ke TFLite, dan mengembangkan aplikasi Android sebagai wadah implementasinya.
Hasil
Aplikasi Android berbasis TFLite yang mengklasifikasikan motif ukiran Toraja on-device, tanpa ketergantungan koneksi internet untuk inferensi utama.
